GENERAL NOTES

This project was created and uploaded using the URP pipeline, and the project you open after downloading it is a URP project!

For the HDRP version:
If there is a folder for HDRP inside the project:
1. Drag the package in the 'HDRP' folder into a new HDRP Unity project.
2. Please check your project's graphics and quality settings are set to 'HDRP'.

For the Built-in version:
If there is a folder for Built-in inside the project:
1. Drag the package in the 'Builtin' folder into a new Built-in Unity project.
2. Please check your project's graphics and quality settings are set to 'None'.
3. Please install shadergraphs from the package manager.
