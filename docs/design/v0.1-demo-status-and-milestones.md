## Status Legend [v0.1]

- `Implemented` = present in repository with concrete runtime/tests evidence.
- `In Progress` = partial implementation exists, but acceptance criteria are not complete.
- `Planned` = target exists in scope docs, but implementation is not complete.
- `Superseded` = original requirement replaced by a newer accepted contract.

## Current Focus Lock [v0.1]

- M1 shipping focus is one authored assassination demo path in `MainTown`, built on the current contract-prep-escape seams.
- Freeze further `MainTown` shell expansion, terrain beautification, and floating-origin follow-on work until that demo path is reproducible without editor intervention.
- Reuse the existing `Contracts` tab intake, `PlayerDevice` validation flow, `PoliceHeatRuntime` payout gate, scoped `.308` rifle path, shop flow, and reloading acceptance coverage instead of opening new system fronts.
- Do not pull vehicles, hunting, competitions, underworld progression, or ELR/floating-origin combat follow-up into the M1 critical path.
- After M1 is stable, the next expressive addition remains one specialty-ammo or contract-modifier slice, not broader sim breadth.

## Milestone Plan [v0.1/demo]

### Milestone M0 - Runtime Foundation (Completed)

Completed outcomes:
- World scene topology and bootstrap entry flow established.
- MainTown <-> IndoorRange round-trip travel implemented and regression-tested.
- Core persistence slice for inventory/weapons/world-object state implemented.
- Basic inventory and trade flow wiring operational in runtime architecture.

Primary evidence:
- `RoundTripTravelPlayModeTests`
- `WorldObjectStateSaveModuleTests`
- `EconomyControllerCheckoutPlayModeTests`

### Milestone M1 - Demo Core Loop (Current Target)

Target outcome:
- Player can accept one procedural assassination contract, prepare a rifle/load/optic, optionally validate the setup, kill a distant target, and escape police attention long enough to cash out.
- The demo should read as assassination sandbox first, with prep systems amplifying the job rather than replacing it.

Exit criteria status (2026-03-06):
- Single-stage press interaction criterion is met with explicit end-to-end PlayMode acceptance coverage.
- Range/group-size validation criterion is met and reflected as `Implemented` in this board.
- Contract-generation and police-heat criteria are now `In Progress`.
- Arrest/death consequence criteria are still `Planned`.
- Save/load demo-loop criterion remains in progress pending remaining non-workbench module targets and future contract/heat state coverage.
- MainTown authored scene-default smoke checks remain open and now need contract-loop authoring coverage rather than range-only smoke coverage.
- MainTown contract-loop and world/travel smoke coverage are green in the targeted reset filters; widening beyond the reset suite is a hardening task, not an M1 blocker.
- The next product-defining addition after the foundation slice should be expressive job restrictions and specialty ammo, not more generic sim breadth.

Current focus lock (2026-03-25):
- Reuse the existing contract slice seams to prove one small but complete assassination demo before more world or tech breadth.
- Floating-origin slice-one acceptance is sufficient for M1; projectile authority, bullet-cam, ELR hit-resolution, and broader travel hardening are not M1 blockers.
- `MainTown` work must now optimize for playable demo readability and reliable smoke coverage, not map size.

Integration snapshot:
- Workbench mount graph slice is integrated on `main`.
- Scoped PiP optics runtime on `main` now covers authored PiP rendering, fixed/variable magnification behavior, FFP/SFP reticle handling, and runtime windage/elevation snapshot restore; live zero-step exposure remains narrower than the shipped windage/elevation path.
- Existing world, persistence, trade, contract, and police-heat slices provide the current foundation for the contract vertical slice.

### Milestone M2 - Demo Hardening (Next)

Target outcome:
- Stable candidate for external demo sessions.

Exit criteria:
- Regression suites for travel, inventory, persistence, weapons, trade, and contract loop run clean on the release branch.
- Docs and plans are synchronized: no checklist says "planned" for already-shipped work.
- Demo script (accept contract -> prep loadout -> shoot -> escape -> cash out -> save/load -> continue) is reproducible without editor intervention.
